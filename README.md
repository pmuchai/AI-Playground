# AI-Playground
Hands on experimentation of AI concepts and findings

# Set-up
- Activate your Azure subscription as part of your FTE benefits
- Login to Azure Portal: https://portal.azure.com/
- Create a resource group
- Create an Azure Open AI instance
- Create an Azure AI Search instance
- Login to Azure AI Foundry to access your Azure Open AI instance
- Deploy the gpt-5-mini and text-embedding-3-small
- Update the config values in launchSettings.json in line with your instances values
- Run the application and view Swagger API documentation on - http://localhost:5000/swagger/index.html
